# Simple Rule-Based Chatbot
## Description

This is a basic rule-based chatbot developed using Python as part of my internship project.

The chatbot can:

* Respond to greetings such as `hello` and `hi`
* Tell the user its name
* Respond to `how are you`
* Exit the conversation when the user types `bye` or `exit`
* Provide a default response for unknown inputs

## Technologies Used

* Python

## How to Run

1. Make sure Python is installed on your computer.
2. Open the project folder in a terminal or command prompt.
3. Run the following command:

```bash
python chatbot.py
```

4. Start chatting with the chatbot.

## Example

```text
🤖 Chatbot: Hello! I am a simple chatbot.
Type 'bye' to exit the chatbot.

you: hello
Chatbot: Hello! How are you?

you: what is your name
Chatbot: My name is SimpleBot.

you: bye
Chatbot: Goodbye! Have a nice day.
```
